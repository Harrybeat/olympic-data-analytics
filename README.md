# 🏅 Olympic Data Analytics & Dashboard

An interactive **Olympic Data Analytics Dashboard** built using Python, MySQL, Pandas, Plotly, and Streamlit to explore and analyze historical Olympic Games data.

This project transforms raw Olympic data into meaningful insights through **data cleaning, database management, SQL analysis, exploratory data analysis, and interactive visualizations**.

---

## 📌 About the Project

The **Olympic Data Analytics & Dashboard** project is an end-to-end data analytics application designed to analyze historical Olympic Games data.

The project processes raw Olympic data, cleans and structures the dataset, stores the information in a **MySQL database**, performs analytical SQL queries, and presents the results through an interactive **Streamlit dashboard**.

Users can explore athlete participation, countries, events, medals, gender distribution, and historical Olympic trends through interactive charts and filters.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Clean and preprocess historical Olympic data.
- Store structured data in a relational MySQL database.
- Perform data analysis using SQL and Python.
- Analyze athlete and country participation.
- Analyze Olympic medal distributions.
- Identify historical Olympic trends.
- Create interactive data visualizations.
- Build a user-friendly analytics dashboard.
- Demonstrate an end-to-end real-world data analytics workflow.
